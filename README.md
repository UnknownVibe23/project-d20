# Project D20

Project D20 is a personal AI Game Master for solo tabletop play: the LLM
(Mistral API) only narrates, while deterministic Python code owns all
rules and state. Development rules for agents live in
[AGENTS.md](AGENTS.md); project context, phases, and status live in
[PROJECT.md](PROJECT.md).
